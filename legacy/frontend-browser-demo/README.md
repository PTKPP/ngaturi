# Browser demo archive

Snapshot ini dipertahankan hanya untuk histori migrasi dari prototipe browser/localStorage. Import alias di dalamnya menunjuk struktur lama dan arsip ini sengaja tidak runnable sebagai aplikasi atau test suite production.

Jangan menghidupkan kembali runtime ini di `apps/frontend`. Gunakan fixture test dengan repository fake yang mengimplementasikan `ApplicationRepository` bila unit test membutuhkan adapter terisolasi.
